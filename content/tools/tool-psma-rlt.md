Enter the patient's disease state, prior therapies, PSMA-PET result, and organ function to see whether ¹⁷⁷Lu-PSMA-617 is supported by the current evidence, with the reasoning and grade-cited trials behind each answer. Fields act as **gates** (PSMA positivity, mCRPC status, and organ function must be satisfied) before line-of-therapy logic applies. This states what the published evidence supports for a population — it is a proposal for discussion, not a written directive.
